# Payment Knowledge Assistant

## Overview

An AI-powered Payment Knowledge Assistant built using Python, Streamlit, RAG, and LLMs.

This application helps users query payment-related documents and receive intelligent answers.

## Features

* Upload payment documents
* AI-powered question answering
* RAG (Retrieval Augmented Generation)
* Streamlit UI
* Payment domain knowledge base

## Tech Stack

* Python
* Streamlit
* LangChain
* RAG
* Vector Database
* GitHub

## Project Goal

Build an enterprise-grade AI assistant for payment domain professionals.
